# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep criticism about the work
rather than the person, and do not harass anyone. This applies to issues, pull
requests, discussions and any other project space.

## Reporting

If you see or experience behaviour that breaks this code, report it to the
maintainer, [StevenPG](https://github.com/StevenPG), through GitHub. You can
also use GitHub's "Report content" option on the comment, issue or pull request
in question.

Reports are handled privately. The maintainer may remove or edit content, and
may warn, temporarily block or permanently block a participant, following the
enforcement guidelines in the Contributor Covenant.
